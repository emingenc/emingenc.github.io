How this site works

ask the agent how it works

The home page is an AI agent that answers from his own notes. Each question runs this loop in your browser.

  1. planpick the tool
  2. actrun it on his notes
  3. observeread what it returned
  4. evaluatecheck it answers the question

The loop repeats until the answer passes the check.

router
Needle (26M parameters) picks the tool. A 36 MB download, run in this tab.
chat model
SmolLM2 (360M parameters) is optional: it phrases answers. A 278 MB download (369 MB without WebGPU), loaded only if you allow it.
check
a model draft that his notes do not back is dropped.
privacy
both models run in your browser. 0 servers, 0 API calls, no analytics on the home page.
speed
reading a notes file takes about 1 ms (measured 2026-10-17 in Chromium on a laptop, 6 questions).
tests
more than 400 automated tests cover the router, loop, answers and pages.
source
the built site is public at github.com/emingenc/emingenc.github.io. The source repository is private.
